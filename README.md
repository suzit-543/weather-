# Weather Dashboard

A weather web app built with vanilla JavaScript that shows real-time weather data for any city.

## Features
- Real-time weather data from OpenWeatherMap API
- Recent search history saved to localStorage
- 5-day weather forecast
- Dynamic background based on weather condition
- °C / °F temperature toggle
- Geolocation support
- Glassmorphism UI design

## Tech Used
- HTML, CSS, Vanilla JavaScript (ES6+)
- OpenWeatherMap API
- ES6 Modules
- localStorage

## How to Run Locally
1. Clone this repo
2. Copy `key.example.js` and rename it to `key.js`
3. Add your OpenWeatherMap API key inside `key.js`
4. Open `weather.html` with Live Server
